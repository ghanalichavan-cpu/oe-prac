## Practicals Covered

1. **Office and Image Editing:** Created a technical document in LibreOffice Writer, an automated calculation sheet in LibreOffice Calc, and edited images using GIMP.
2. **Video Editing and 3D Modelling:** Edited video clips with transitions and audio in Shotcut and created a low-poly object in Blender.
3. **Git Version Control:** Created a local Git repository, tracked files, committed changes, used branches, and resolved a merge conflict.
4. **GitHub Collaboration:** Worked with a remote repository and learned about pushing changes and pull requests.
5. **Wikipedia Editing:** Practised sandbox editing, citation formatting, and expanding an article.
6. **Linux Commands:** Practised commands such as `cd`, `ls`, `pwd`, `grep`, `awk`, `cat`, and pipes.
7. **Linux Administration:** Practised file permissions, ownership, and package management.
8. **Virtualization and Containers:** Used Oracle VirtualBox and practised Docker image and container operations.
9. **Web Server and Website:** Set up a local Apache server and practised creating a WordPress website using a LAMP/WAMP environment.
